# Anirud Nandakumar — Academic Website

Personal academic website, built on a minimal HTML/CSS template
(adapted from https://github.com/jonbarron/jonbarron_website via
https://vinayak-vg.github.io/).

## Structure
- `index.html` — main page
- `stylesheet.css` — styling
- `images/` — profile photo and project images (currently placeholders)
- `pdfs/` — CV and paper PDFs (add `Anirud_Nandakumar_CV.pdf`)
- `bibs/` — BibTeX citations for publications

## To customize
- Replace `images/profile_placeholder.png` with your photo
- Replace `images/placeholder_project.png` files with project thumbnails
- Add your CV to `pdfs/Anirud_Nandakumar_CV.pdf`
- Update links (Scholar, LinkedIn, paper/code links) in `index.html`

## Deploy
This is a GitHub Pages site. If the repo is named `<username>.github.io`,
it deploys automatically at `https://<username>.github.io`.
